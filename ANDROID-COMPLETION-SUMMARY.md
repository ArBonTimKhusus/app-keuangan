## 🚀 Cara Menggunakan

### Untuk Developer

#### Opsi 1: Android Studio
```bash
1. Extract arbonkas-android.zip
2. Buka Android Studio
3. File > Open > Pilih folder android-package
4. Wait for Gradle sync
5. Build > Build Bundle(s) / APK(s) > Build APK
6. APK di: app/build/outputs/apk/debug/app-debug.apk
```

#### Opsi 2: Command Line
```bash
unzip arbonkas-android.zip
cd android-package
./gradlew assembleDebug
adb install app/build/outputs/apk/debug/app-debug.apk
```

### Untuk End User

```bash
1. Dapatkan file APK dari developer
2. Enable "Install from Unknown Sources" di Android
3. Tap file APK untuk install
4. Grant permissions jika diminta
5. Buka aplikasi dan gunakan!
```
