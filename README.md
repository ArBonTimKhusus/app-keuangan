# ArBonKas 

![ArBonKas Dashboard](https://github.com/user-attachments/assets/d7d8dca5-8e72-4fda-bedb-95b5660d1a07)

**ArBonKas** adalah aplikasi laporan keuangan berbasis web yang dirancang khusus untuk **ArBon Carbon Modifikasi** (https://www.arboncarbonmodifikasi.com). Aplikasi ini terinspirasi dari Sepran.id dan dibuat untuk membantu mengelola keuangan bisnis dengan mudah dan efisien.

## ✨ Fitur Utama

### 📊 Dashboard
- **Ringkasan Keuangan**: Tampilan cepat total pemasukan, pengeluaran, dan saldo
- **Transaksi Terakhir**: Lihat 5 transaksi terbaru dengan cepat
- **Tombol Tambah Cepat**: Akses cepat untuk menambah transaksi baru

### 💰 Manajemen Transaksi
- **Pencatatan Pemasukan & Pengeluaran**: Catat semua transaksi dengan mudah
- **Kategori Transaksi**: Organisir transaksi berdasarkan kategori
- **Filter & Pencarian**: Filter transaksi berdasarkan tipe (pemasukan/pengeluaran)
- **Edit & Hapus**: Kelola transaksi yang sudah ada
- **Catatan Transaksi**: Tambahkan catatan detail untuk setiap transaksi

### 👛 Multi Dompet/Akun
- **Manajemen Dompet**: Kelola beberapa dompet/akun berbeda
- **Saldo Real-time**: Lihat saldo setiap dompet secara otomatis
- **Ikon Kustom**: Pilih ikon untuk setiap dompet (Dompet, Kartu Kredit, Bank, dll)

### 📈 Laporan Keuangan
- **Periode Fleksibel**: Generate laporan untuk hari ini, minggu ini, bulan ini, tahun ini, atau custom
- **Ringkasan Keuangan**: Lihat total pemasukan, pengeluaran, dan saldo untuk periode tertentu
- **Detail Transaksi**: Daftar lengkap semua transaksi dalam periode yang dipilih
- **Ekspor PDF**: Fitur ekspor laporan (coming soon)

### 💸 Hutang & Piutang
- **Manajemen Piutang**: Catat uang yang dipinjamkan kepada orang lain
- **Manajemen Hutang**: Catat hutang yang harus dibayar
- **Status Tracking**: Pantau status aktif/lunas untuk setiap hutang/piutang
- **Tanggal Jatuh Tempo**: Set reminder dengan tanggal jatuh tempo

## 🚀 Teknologi

- **HTML5**: Struktur aplikasi modern
- **CSS3**: Styling responsif dengan custom CSS variables
- **Vanilla JavaScript**: Tidak ada dependencies, aplikasi ringan dan cepat
- **Local Storage**: Penyimpanan data offline di browser
- **Font Awesome**: Ikon modern dan profesional

## 📱 Fitur Unggulan

### ✅ Offline First
- **Tidak Perlu Internet**: Semua data disimpan lokal di perangkat
- **Privasi Terjamin**: Data hanya tersimpan di browser Anda
- **Cepat & Responsif**: Tidak ada delay loading dari server

### 🎨 User Interface
- **Desain Modern**: Interface yang clean dan mudah digunakan
- **Responsif**: Bekerja sempurna di desktop, tablet, dan mobile
- **Animasi Halus**: Transisi yang smooth antar halaman

### 🔒 Keamanan & Privasi
- **Data Lokal**: Semua data tersimpan di browser pengguna
- **Tidak Ada Server**: Tidak ada data yang dikirim ke server eksternal
- **Privacy by Design**: Anda yang mengontrol penuh data Anda

## 🛠️ Cara Menggunakan

### Instalasi
1. Clone atau download repository ini
2. Buka file `index.html` di browser modern (Chrome, Firefox, Edge, Safari)
3. Aplikasi siap digunakan!

### Penggunaan

#### Menambah Transaksi
1. Klik tombol **"Tambah Cepat"** di Dashboard atau **"Tambah Transaksi"** di halaman Transaksi
2. Pilih tipe (Pemasukan/Pengeluaran)
3. Masukkan jumlah, kategori, dan pilih dompet
4. Tambahkan catatan jika diperlukan
5. Klik **"Simpan"**

#### Menambah Dompet
1. Buka halaman **Dompet**
2. Klik **"Tambah Dompet"**
3. Masukkan nama dompet dan saldo awal
4. Pilih ikon yang sesuai
5. Klik **"Simpan"**

#### Generate Laporan
1. Buka halaman **Laporan**
2. Pilih periode (Hari Ini, Minggu Ini, Bulan Ini, Tahun Ini, atau Custom)
3. Klik **"Generate"**
4. Lihat ringkasan dan detail transaksi

#### Mengelola Hutang/Piutang
1. Buka halaman **Hutang/Piutang**
2. Pilih tab Piutang atau Hutang
3. Klik **"Tambah"**
4. Isi detail (nama, jumlah, tanggal, jatuh tempo)
5. Klik **"Simpan"**

## 📱 Versi Android

### ArBonKas Android Package

Tersedia **package Android** lengkap yang bisa di-build menjadi APK!

📦 **Download**: `arbonkas-android.zip` (27 KB)

#### Fitur Android Package:
- ✅ **Source Code Lengkap** - Siap di-build dengan Android Studio
- ✅ **WebView Wrapper** - Native Android app wrapper
- ✅ **Offline-First** - Bekerja tanpa internet
- ✅ **LocalStorage** - Data tersimpan aman di device
- ✅ **Min SDK 21** - Kompatibel dengan Android 5.0+
- ✅ **Dokumentasi Lengkap** - README dan INSTALL guide

#### Quick Start Android:
```bash
# Ekstrak package
unzip arbonkas-android.zip
cd android-package

# Build menggunakan Gradle
./gradlew assembleDebug

# Install ke device Android
adb install app/build/outputs/apk/debug/app-debug.apk
```

#### Build di Android Studio:
1. Extract `arbonkas-android.zip`
2. Open Android Studio
3. File > Open > Pilih folder `android-package`
4. Build > Build Bundle(s) / APK(s) > Build APK(s)
5. APK tersimpan di `app/build/outputs/apk/debug/`

📖 **Dokumentasi Lengkap**: Lihat `ANDROID-PACKAGE-INFO.md` untuk detail lengkap

#### Apa yang Ada di Package?
- 📱 MainActivity.java - WebView wrapper
- 🎨 Android UI resources (layouts, styles, strings)
- 📦 Web assets (HTML, CSS, JS)
- ⚙️ Build configuration (Gradle)
- 📚 Dokumentasi lengkap (README, INSTALL guide)
- 🔧 ProGuard rules untuk optimization

#### Persyaratan Build:
- Android Studio Arctic Fox atau lebih baru
- JDK 8+
- Android SDK API Level 33

#### Persyaratan Runtime:
- Android 5.0 (API 21) atau lebih tinggi
- 50 MB storage
- Tidak perlu internet connection
