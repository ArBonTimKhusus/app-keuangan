# 📊 Aplikasi Keuangan

Aplikasi manajemen keuangan berbasis web dengan fitur kategori dan ekspor multi-format.

## ✨ Fitur

### 1. Manajemen Kategori
- ✅ Tambah kategori custom untuk mengorganisir catatan keuangan
- ✅ Hapus kategori yang tidak diperlukan
- ✅ Kategori default: Gaji, Makanan, Transport, Belanja, Hiburan, Lainnya

### 2. Catatan Keuangan
- ✅ Catat pemasukan dan pengeluaran
- ✅ Pilih kategori untuk setiap transaksi
- ✅ Tambahkan deskripsi untuk setiap catatan
- ✅ Tampilan ringkasan total pemasukan, pengeluaran, dan saldo

### 3. Ekspor Data
Ekspor laporan keuangan ke berbagai format:
- 📄 **PDF** - Format profesional untuk laporan
- 📊 **Excel** - Untuk analisis lebih lanjut
- 📝 **Word** - Dokumen yang dapat diedit
- 📽️ **PowerPoint** - Presentasi laporan keuangan

## 🚀 Cara Menggunakan

1. Buka file `index.html` di browser
2. Tambahkan kategori sesuai kebutuhan
3. Mulai mencatat transaksi keuangan
4. Lihat ringkasan di dashboard
5. Ekspor data sesuai kebutuhan

## 💾 Penyimpanan Data

Data disimpan secara lokal menggunakan localStorage browser, sehingga data tetap tersimpan meskipun browser ditutup.

## 🛠️ Teknologi

- HTML5
- CSS3
- JavaScript (Vanilla)
- jsPDF - Export PDF
- SheetJS (xlsx) - Export Excel
- docx - Export Word
- PptxGenJS - Export PowerPoint

## 📱 Responsive Design

Aplikasi dioptimalkan untuk desktop dan mobile device.
